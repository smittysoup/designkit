# Maintaining DesignKit
Build tools for transforming business processes into bounded agent operating models.
Do not copy private inputs or customer artifacts into this public repository.
Keep authoring assistants distinct from business agents. Never fabricate reviews.
Run `python -m unittest discover -s tests -v` for CLI changes and
`node scripts/browser-check.mjs` for CaseFlow changes (see docs/testing.md).
Preserve authored files and stable IDs; no global configuration writes.
Regenerate actual captures after prototype changes. Review manifest gates and
Spec Kit reconciliation when interfaces change. Disclose AI-assisted contributions.
