# Experience guidance

Synthetic CaseFlow reference. Authored design hypothesis; no stakeholder acceptance or production performance claim.

## Interaction

Make the next human action primary, with waiting reason, case revision and retained final authority visible. Show simulated agent events separately from the next decision. Expand run details on demand; never imply phase navigation completes work. Use native buttons, labels and status announcements.

## Responsive

Two columns at desktop collapse to one under 650px; controls remain full width where needed. Capture 1280×900 and 390×844 emulated viewports. This is not a physical device test. The same fixture drives all views.

## Accessibility

Dark ink on light backgrounds, visible focus rings, semantic headings, labelled fields and aria-live state updates. Empty responses produce an alert. Keyboard controls and horizontal overflow are checked in browser tests. Screen-reader usability and comprehensive contrast/WCAG audit remain design review obligations.
